# GuitarChain

Zero Knowledge Proof based Guitar Authenticity Verification.

## Stack

* Next.js
* Tailwind CSS
* Hardhat
* Solidity
* MetaMask
* Ethers.js
* Circom (planned)
* snarkjs (planned)

---

## Setup

Clone repository:

```bash
git clone <repo-url>
cd guitarchain
```

Install smart contract workspace:

```bash
cd contracts
npm install
```

Install frontend:

```bash
cd ../frontend
npm install
```

Run frontend:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
